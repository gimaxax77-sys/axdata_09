## 한 줄 결론

**현재 구조로는 "컨셉·레퍼런스·프로토타입" 등급의 아트를 장당 ~$0.04에

## 1. 이미지 엔진(Gemini 2.5 Flash Image) 경쟁력

- **가격**: 출력 100만 토큰당 $30, 이미지 1장 = 1,290토큰 ≈ **$0.039/장**
  (2025년 10월 GA). — developers.googleblog.com, openrouter.ai
- **해상도/비율**: 1:1~21:9 등 10종 비율, 기본 ~1024px급. 상위 티어(Nano
  Banana Pro/2)는 1K/2K/4K를 $0.03/$0.05/$0.06에 제공. — unifically.com
- **강점**: 빠른 속도(수 초), 자연어 편집, 다중 이미지 합성, **평균 이상의
  캐릭터 일관성**. — developers.googleblog.com
- **약점(게임 아트 관점)**: **네이티브 알파(투명 배경) 미지원 — 투명을
  요청해도 평면 RGB로 출력.** 개발자들은 흰 배경/검은 배경 2장을 생성해
  차이로 투명도를 복원하는 우회법을 씀. — jidefr.medium.com,
  roboticape.com (※ 두 출처는 페이지 403, 검색 요약으로만 확인 — **중신뢰**)
- **경쟁 구도**: Midjourney v7이 기본 퀄리티·부분 재생성(Vary Region)에서
  우위, Gemini는 속도·반복 편집·출처(SynthID)에서 우위, **FLUX.2**(2025.11)는
  최강 오픈웨이트, OpenAI **gpt-image-1**은 정확한 텍스트 렌더 + **진짜 투명
  배경** + 레퍼런스 이미지 16장 지원. — skywork.ai, neuralstackly.com,
  developers.openai.com
  - 참고: gpt-image-1은 1024²에서 $0.011~0.167, 단 **2026-10-23 지원 종료
    예정**. — costgoat.com

## 2. "프로덕션 에셋"의 실제 요건 (컨셉과의 차이)

프로덕션 2D 에셋에 필요한 것: **투명 알파 PNG**, 프레임별 개별 export +
원본 파일, 일정한 픽셀 밀도, 캐릭터당 대개 <500KB, 애니메이션용 깨끗한
프레임 경계. 추가로 타일러블 타일셋, PBR 맵 세트(알베도/러프니스/**노멀**/
높이), 피벗/앵커 정의, 스타일 통일된 모듈형 킷. — help.author.envato.com,
pixune.com, ilogos.biz

**이 툴에의 함의**: RGB를 고정 크기로 불투명 배경에 크롭하는 방식은
**컨셉·레퍼런스급** 산출물이지, 알파 복원과 스타일 고정 없이는 엔진에 바로
넣는 스프라이트가 아님.

## 3. 캐릭터 일관성 — 가장 어려운 문제

보고된 정확도 계층: **시드 고정 40~60%**(노이즈만 고정, 프롬프트 바뀌면
발산) → **네이티브 레퍼런스 이미지 80~90%** → **IP-Adapter/ControlNet
90~95%** → **LoRA(15~30장 학습) 95~99%**. — skywork.ai, honeychat.bot

Gemini는 **다중 레퍼런스 이미지 컨디셔닝 + 자연어 편집 일관성**을 네이티브
지원(Pro는 참조 ~14장까지 "브랜드 바이블"). LoRA/IP-Adapter는 미지원(그건
Stable Diffusion 계열). **이 툴은 텍스트 프롬프트만 쓰고 image-to-image
컨디셔닝이 없어, 가장 약한 계층(시드/프롬프트 고정 ~40~60%)에 해당** —
초상화·전신·표정을 따로 생성하면 얼굴/복장이 서로 달라지는 최악의 실패
모드. — developers.googleblog.com, help.apiyi.com

## 4. 법적/라이선스 (상업적 사용)

- **상업적 사용 허용**: Google·OpenAI 모두 출력물 소유권을 사용자에게 주고
  로열티 없는 상업 사용 허용. — terms.law, glbgpt.com
- **저작권**: 순수 AI 생성물은 **미국에서 저작권 등록 불가**(인간 창작성
  요건). *Thaler v. Perlmutter* DC항소법원 확정(2025.3), **대법원 상고 기각
  (2026.3)**. 인간의 "선택·배열·조정"이나 인페인팅이 있으면 **편집·혼합
  저작물**로 일부 보호 가능. — copyright.gov/ai, morganlewis.com
  - 실무적 의미: **팔 수는 있으나 남이 베껴도 막기 어려움.**
- **표시**: Gemini는 모든 이미지에 비가시 **SynthID 워터마크** 삽입. Steam은
  AI 콘텐츠 고지 요구(아래).

- **컨셉/아이데이션**: 캐릭터·몬스터·세계관 시안을 분 단위로 대량 탐색
- **프리프로덕션/피치덱**: 무드보드, 룩 개발, 투자·팀 공유용 비주얼

## 격차 해소 로드맵 (이 툴을 프로덕션급에 근접시키려면)

우선순위 순:

1. **캐릭터 일관성** — 초상화를 먼저 1장 생성하고, 그 이미지를 **레퍼런스로
   전달(image-to-image)** 해 전신·표정·포즈를 파생. Gemini 다중 레퍼런스
   컨디셔닝을 사용하면 ~80~90%까지 상승. (현재 텍스트-only 대비 최대 개선폭)
2. **진짜 투명 배경** — 흰/검 2장 생성 후 차이로 알파 복원, 또는 배경 제거
   후처리(rembg 등) 파이프라인 추가 → 게임 스프라이트로 사용 가능.
3. **상위 모델 옵션** — `GEMINI_IMAGE_MODEL`을 Nano Banana Pro/2(고해상·다중
   레퍼런스)로 교체 가능하게, 또는 투명 지원 gpt-image-1 백엔드 추가.
4. **스프라이트 시트 export** — 변형(표정/포즈)들을 하나의 아틀라스+피벗
   메타로 묶어 엔진 임포트 편의 제공.
5. **스타일 락** — 프로젝트 단위 스타일 기준 이미지를 모든 에셋에 참조로
   주입해 룩 통일.

이 중 **1(일관성)과 2(알파)** 만 구현해도 "컨셉 도구"에서 "인디 프로덕션에
쓸 만한 도구"로 등급이 올라갑니다.
