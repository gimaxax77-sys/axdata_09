# AXData Studio — 전체 레이아웃 · 옵션 점검 브리핑

전체 화면과 모든 메뉴/옵션을 재점검한 결과 정리. (발견 이슈는 조치 완료)

---

## 1. 전체 레이아웃 (3영역)

```
┌───────────────────────────── 상단바 ─────────────────────────────┐
│ ◈ AXData Studio        [사용량 바] [GPT 상태] [Gemini 상태]        │
├──────────────────────────┬──────────────────────────────────────┤
│  좌측: 입력 폼            │  우측: 결과 패널                       │
│  (모드/대상/옵션/에셋)   │  (안내·ZIP·헤더·에셋·스탯·설정·시트·영상)│
└──────────────────────────┴──────────────────────────────────────┘
```
- 반응형: 좁은 화면(≤860px)에서 1열로 전환.

## 3. 좌측 입력 폼

### 모드 토글
- **단일 생성** / **일괄 생성 · 도감**

### 1. 대상 설정
| 옵션 | 값 | 비고 |
|------|-----|------|
| 대상 타입 | 캐릭터 / 몬스터 / NPC | 타입별 스탯·정보·라벨 자동 변경 |
| 이름 | 자유 입력 | 비우면 자동 생성 |
| 장르 | 8종(판타지/SF/사이버펑크/무협/스팀펑크/동화풍/호러/포스트아포칼립스) | |
| 직업/역할 | 자유 입력 | 타입에 따라 라벨 변경(종족/유형) |
| 아트 스타일 | **프리셋 11종 드롭다운 + 직접 입력** | ✅ 개선됨(아래 이슈①) |
| 추가 키워드 | 쉼표 구분 | |
| 이미지 크기 | 표준 / 크게 / 작게 | 비용·해상도 영향 |

### 고급 (실 API 권장)
| 토글 | 기본 | 효과 |
|------|------|------|
| 캐릭터 일관성 | ON | 초상화를 앵커로 동일 인물 유지 |
| 스타일 락 | OFF | 전체 에셋 룩·팔레트 통일 |
| 투명 배경(PNG) | OFF | 컷아웃 에셋 배경 제거 |
| 스프라이트 시트 | OFF | 변형을 아틀라스+메타로 패킹 |

### 일괄 모드 전용
- 생성 개수(1~8), 도감 오버뷰 생성, 역할/종족 목록(줄단위)

### 2. 생성할 아트 요소 (체크리스트, 전체/해제/기본)
6개 카테고리 · 총 26종 이미지 + 통합 2종. (아래 5절 참고)

## 4. 우측 결과 패널
안내(경고) → **📦 전체 ZIP** → 캐릭터 헤더(타입 배지·이름·타이틀·태그라인·팔레트)
→ 아트 에셋(카테고리 그룹) → 스탯 / 정보 2단 → 외형·성격·배경·능력
→ 캐릭터 시트(PNG/PDF) → 쇼케이스 영상(GIF/MP4·CapCut 스토리보드)
- 일괄 모드: 도감 오버뷰 + 개체별 확장(▸) 카드.

## 5. 아트 요소 전체 & 중복/충돌 분석

| 카테고리 | 요소 | 변형 | 일관성참조 | 컷아웃 |
|----------|------|------|:---:|:---:|
| 캐릭터 | 초상화 | 1 | ✅ | ✅ |
| 캐릭터 | 전신 | 1 | ✅ | ✅ |
| 캐릭터 | 표정 세트 | 가변 | ✅ | ✅ |
| 캐릭터 | 액션 포즈 | 가변 | ✅ | ✅ |
| 캐릭터 | 도트 스프라이트 | 1 | ✅ | ✅ |
| 캐릭터 | 턴어라운드 | ×3 | ✅ | ✅ |
| 캐릭터 | 엠블럼 | 1 | ✖(심볼) | ✅ |
| 캐릭터 | 이모트 | 가변 | ✅(개선) | ✅ |
| 캐릭터 | 탈것/펫 | 1 | ✖(별개 생물) | ✅ |
| 아이템 | 무기·방어구(×3) / 인벤토리 / 스킬(가변) / 등급(×5) | | ✖ | 일부 ✅ |
| 환경 | 배경 / 타일셋 / 스카이박스 | | ✖ | ✖ |
| UI | 로고 / TCG카드 / 배너 / 스플래시 / 프로필 | | 카드·스플래시·프로필만 ✅ | ✖ |
| HUD | 버튼(가변) / 기능(가변) / 재화(가변) / 패널 / HUD바 | | ✖ | 아이콘류 ✅ |

### 중복/충돌 판정
- **기술적 충돌: 없음** — 각 에셋은 독립 생성, 서로 간섭하지 않음.
- **표정 세트 ↔ 이모트**: 둘 다 얼굴 감정 변형 → **용도가 다름**(VN 대화용 정식 초상 vs 채팅용 스티커). 둘 다 선택하면 결과가 유사할 수 있어 **선택적 중복**. 둘 중 필요한 것만 권장.
- **탈것/펫**: 캐릭터 카테고리이나 *주인공이 아닌 별개 생물* → 일관성 참조에서 **의도적으로 제외**(펫이 주인공 얼굴이 되면 안 되므로). 정상.
- **엠블럼**: 인물 형상이 아닌 심볼이라 일관성 참조 제외. 정상.
- **아이콘 다수(엠블럼/기능/재화/스킬/무기)**: 용도가 모두 달라 충돌 아님.
- **무기·방어구 아이콘**: 몬스터에는 미표시(정상).

## 7. 주의/권장 사항 (충돌은 아니나 알아둘 점)

- **이미지 크기 '크게' + 배경/배너/스플래시**: 대형 이미지라 비용↑. 아이콘류는 '표준' 권장.
- **gpt-image-1 모델 선택 시**: OpenAI 키 필요(투명 네이티브 지원). Gemini 키만 있으면 기본(Gemini) 사용.
- **스타일 락·일관성·투명**: 실 API 에서 효과가 나타남(데모는 플레이스홀더).
- **변형 10개 + 여러 가변 에셋 동시**: 이미지 장수가 급증 → 비용 주의.
- **일괄(도감) × 많은 에셋**: 개체수 × 에셋수만큼 곱해짐. 처음엔 작게 테스트 권장.
