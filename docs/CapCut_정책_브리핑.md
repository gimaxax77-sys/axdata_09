2025~2026 웹 리서치 기반. (출처 사이트가 직접 fetch 차단되어 검색 요약 + URL 기준)

## 먼저: 이 툴의 "영상"은 두 가지

| 산출물 | CapCut 필요? | 제한 |
|--------|:---:|------|
| **쇼케이스 GIF / MP4** (Pillow/ffmpeg 로 로컬 생성) | ❌ 불필요 | **없음** — 워터마크·갯수·요금제 무관, 상업 사용 자유 |
| **CapCut draft** (편집용 프로젝트 파일) | ⭕ CapCut 앱에서 열어 편집·export | 아래 CapCut 정책 적용 |

> **핵심**: 툴이 만드는 **GIF/MP4는 CapCut과 무관하게 로컬에서 생성**되므로 어떤 제한도 없습니다.
> CapCut 정책은 "draft를 CapCut 앱에서 열어 더 화려하게 편집·export할 때"만 해당됩니다.

## CapCut 정책 요약 (2025~2026)

### 1. 요금제
| 티어 | 가격 | 주요 |
|------|------|------|
| Free | $0 | 기본 편집 전체, 기본 AI 자막/컷, **1080p** export |
| Standard | ~$9.99/월 | 워터마크 제거, 1080p |
| **Pro** | **$19.99/월 또는 $179.99/년** (앱스토어 결제 시 더 높음) | **4K/60fps/HDR**, 전체 AI, 클라우드 |

출처: capcut.com/resource, bigvu.tv, costbench.com (2026)

### 2. 갯수 제한 (export)
- **기본 export(무료 소재만 사용): 제한 없음** — 워터마크·길이·횟수 제한 없음
- 단, **Pro 전용 소재(템플릿/효과/전환/폰트/음악/AI효과)를 쓴 프로젝트**는 무료 사용자 시 **주당 약 3~4회 export 후 차단**(포럼 보고, 공식 페이지 아님)

### 3. 워터마크
- **무료 + 무료 소재로 수동 export → 보통 워터마크 없음** (끝부분 CapCut 로고는 export 설정에서 끌 수 있음)
- **Pro 템플릿·일부 AI 클립·프리미엄 음악**을 남겨두면 워터마크 강제 (자료 간 상충 있음 — 위 조건이 안전)

### 4. 해상도
- 무료/Standard: **1080p** · Pro: **4K 60fps HDR**. 수동 export 길이 제한 없음.

### 5. ⚠️ 상업 이용 · 라이선스 (중요)
- **2025년 6월 ToS 개정**: CapCut/ByteDance가 사용자 콘텐츠(**드래프트·미공개 포함**)에 대해
  "무조건·철회불가·양도가능·영구·전세계" 라이선스를 획득. **삭제/탈퇴 후에도 유지, 옵트아웃 불가.**
  광고·홍보에 사용 및 제3자 서브라이선스 가능. (capcut.com/clause/terms-of-service, techradar.com, isabokelaw.com)
- **내 export 자체는 상업 사용 가능**(비독점 라이선스라 권리 보유). 논란은 ByteDance도 광범위한 권리를 갖는 점.
- **CapCut 내장 음악/효과는 개인·비상업(인앱) 용도** — "상업용" 라벨도 대개 TikTok/CapCut 한정. 유튜브/클라이언트
  작업엔 **외부 로열티프리 음원 사용 권장** (Content ID 클레임 빈번). (artyfile.com, soundcy.com)

### 6. AI 기능
- 별도 **AI 크레딧** 소모 + Pro 게이팅. Pro 월 크레딧 자료 상충(약 200 vs 1,200). 기본 자막/컷은 무료.

### 7. 이용 가능 여부
- **미국**: 2025.1.19 잠시 삭제 → 1.21 복구, 현재 이용 가능(정치적으로 유동적). **인도: 2020년부터 영구 금지.**

### 8. API / 자동화
- **공식 렌더링 API 없음.** 프로그램으로 프로젝트 생성·씬 추가·MP4 렌더 불가.
- 이 툴의 **draft 파일 생성은 비공식(내부 draft 포맷)** — 문서화 안 됨, CapCut 버전업 시 깨질 수 있음.

## 이 툴 사용자에게 주는 권장사항

1. **대부분의 경우 CapCut 불필요** — 툴의 **MP4(imageio-ffmpeg)** 로 충분. 워터마크·갯수·요금제 제약 0, 상업 사용 자유.
2. **더 화려한 편집이 필요할 때만 CapCut** — 무료 티어 + **무료/자체 소재만** 쓰면 1080p 워터마크 없이 무제한 export.
3. **⚠️ 미공개 게임 IP는 CapCut 업로드 주의** — ToS상 ByteDance가 드래프트 콘텐츠에 광범위 라이선스를 가짐.
   민감한 상업 IP는 **로컬 MP4**로 처리하거나 CapCut 외 에디터 사용을 권장.
4. **상업 배포 시 음악은 외부 로열티프리** 사용 (CapCut 내장 음원 회피).
5. **Pro는 4K/HDR·고급 AI가 꼭 필요할 때만** ($19.99/월). 캐릭터 쇼케이스 1080p면 무료로 충분.

## 확인 불가(플래그)
- ToS 정확한 현재 문구 (사이트 직접 fetch 차단 — 라이브 페이지 재확인 필요)
- 무료 export 주당 제한 수치 (포럼 출처, 공식 아님)
- Pro AI 크레딧 월 할당량 (자료 상충 200 vs 1,200)
