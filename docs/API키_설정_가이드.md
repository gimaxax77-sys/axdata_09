# 아트 스튜디오 API 키 설정 가이드

이 문서는 아트 스튜디오(AXData Studio)를 **데모 모드**에서 **실제 아트 생성 모드**로
바꾸는 방법을 처음부터 끝까지 안내합니다. 키를 넣지 않으면 지금처럼 무료 데모
플레이스홀더가 나오고, 키를 넣으면 진짜 일러스트·기획이 생성됩니다.

> 결론부터 말하면, `.env` 파일 하나를 만들어 키 두 개를 붙여넣고 서버를 켜면 됩니다.

---

## 1. 어떤 키가 필요한가

아트 스튜디오는 두 개의 AI를 씁니다. 둘 중 **하나만 넣어도** 그 부분만 실제로 동작하고,
나머지는 데모로 채워집니다.

| 키 | 하는 일 | 없으면 |
| --- | --- | --- |
| `OPENAI_API_KEY` | 캐릭터 **기획/설정 텍스트** 생성 (GPT) | 데모 기획 생성기로 대체 |
| `GEMINI_API_KEY` | 캐릭터 **아트 이미지** 생성 (Gemini) | Pillow 플레이스홀더로 대체 |

게임 아트가 목적이라면 **`GEMINI_API_KEY`가 핵심**입니다.

---

## 2. 키 발급받기

### OpenAI (GPT)
1. https://platform.openai.com/api-keys 접속 후 로그인.
2. **Create new secret key** 클릭 → 이름 입력 → 생성.
3. `sk-...`로 시작하는 키를 복사합니다. (**이때 한 번만 보여주므로 꼭 복사**)
4. 결제 수단 등록이 필요합니다(Billing). 사용한 만큼 후불로 청구됩니다.

### Google Gemini (아트)
1. https://aistudio.google.com/apikey 접속 후 구글 계정 로그인.
2. **Create API key** 클릭 → 프로젝트 선택/생성 → 생성.
3. `AIza...`로 시작하는 키를 복사합니다.

---

## 3. `.env` 파일 만들기

아트 스튜디오 폴더(`axdata_09`)에 이미 견본 파일 `.env.example`이 있습니다.
이걸 복사해서 `.env`라는 이름으로 만들고, 키를 채웁니다.

**Windows (명령 프롬프트)**
```bat
copy .env.example .env
notepad .env
```

**macOS / Linux**
```bash
cp .env.example .env
nano .env      # 또는 원하는 편집기
```

`.env` 안에서 아래 두 줄의 `=` 뒤에 복사한 키를 붙여넣습니다.

```
OPENAI_API_KEY=sk-여기에_복사한_OpenAI_키
GEMINI_API_KEY=AIza여기에_복사한_Gemini_키
```

> ⚠️ `.env`는 비밀번호와 같습니다. **깃(Git)에 커밋하지 마세요.**
> (이 저장소는 `.gitignore`로 `.env`를 이미 제외하고 있습니다.)

저장할 이미지 폴더를 바꾸고 싶으면 같은 파일의 `OUTPUT_DIR`도 조정할 수 있습니다.

## 4. 서버 켜고 확인하기

**Windows**
```bat
start.bat
```

**직접 실행 (모든 OS)**
```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

브라우저에서 `http://127.0.0.1:8000` 접속하면 웹 UI가 열립니다.

**키가 잘 들어갔는지 확인** — 아래 주소를 열어보세요.
```
http://127.0.0.1:8000/api/status
```
- `{"gpt":"live","gemini":"live"}` → 실제 모드 (키 인식됨) ✅
- `{"gpt":"demo","gemini":"demo"}` → 아직 데모 모드 (키 확인 필요)

## 5. 게임 다리(sync-art)와 함께 쓰기

키를 넣고 서버를 켠 상태에서, 게임 저장소(`axdata_01`)에서 다리를 실행하면
**진짜 일러스트**가 채워집니다. 스크립트는 그대로입니다.

```bash
# axdata_01 에서
ART_API=http://127.0.0.1:8000 npm run sync-art       # 초상
ART_API=http://127.0.0.1:8000 npm run sync-sprites   # 전투 스프라이트
```

이미 있는 그림은 건너뛰므로, 새로 추가한 캐릭터만 채워집니다.
특정 캐릭터를 다시 뽑고 싶으면 그 PNG를 지우고 다시 실행하거나 `--force`를 씁니다.

## 6. 비용 주의

- 실제 모드는 **생성할 때마다 요금이 발생**합니다(이미지 1장·기획 1건 단위).
- 아트 스튜디오 UI의 **사용량/예상 비용** 표시와 **예산(Budget)** 기능으로 관리하세요.
- 처음에는 캐릭터 1~2명만 먼저 뽑아 스타일을 확인한 뒤 전체를 돌리는 것을 권합니다.
- 대량 생성 전에는 데모 모드(키 없이)로 배관을 한 번 점검하면 안전합니다.
