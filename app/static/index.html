⚠️ 비용·사용 주의사항
  • 비용은 이미지 장수에 비례 — 변형 10개·여러 가변 에셋·일괄(개체×에셋)은 급증. 처음엔 작게 테스트.
  • 이미지 크기 '크게' + 배경/배너/스플래시 → 대형이라 비용↑. 아이콘류는 '표준' 권장.
  • gpt-image-1 모델은 OpenAI 키 필요(투명 네이티브). Gemini 키만 있으면 기본 사용.
  • 일관성·스타일 락·투명 배경은 실 API에서 효과(데모는 플레이스홀더).
  • 표정 세트 ↔ 이모트는 용도만 다른 유사 얼굴 변형 — 필요한 것만 선택 권장.
  • 실제 잔액은 API로 조회 불가 — 상단 사용량은 추정치. 실 잔액은 각 콘솔에서 확인.

API 키가 없으면 데모 모드(로컬 생성)로 동작합니다. 결과는 outputs 폴더에 자동 저장됩니다.
